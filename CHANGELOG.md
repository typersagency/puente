# Changelog · Registro de cambios

## 1.0.0 — 2026-10-19

First public version. / Primera versión pública.

- Gallery and Camera buttons, with a progress bar per file and an overall one. / Botones de Galería y Cámara, con barra de avance por archivo y general.
- Choose the destination folder from the phone: folder browser, new folder and recent folders. / Elegir la carpeta de destino desde el celular: explorador, carpeta nueva y carpetas recientes.
- Names by capture time; GPS erased on arrival without re-compressing; HEIC → JPG; no duplicates. / Nombres por la hora de la toma; GPS borrado al llegar sin recomprimir; HEIC → JPG; sin duplicados.
- Security: local network only, 8-digit PIN with per-address and network-wide lockout, sign-out that really closes the session, `X-Puente` header, file type by contents, nothing outside the shared folder, log. / Seguridad: solo red local, PIN de 8 números con bloqueo por dirección y para toda la red, salir que cierra la sesión de verdad, encabezado `X-Puente`, tipo por contenido, nada fuera de la carpeta compartida, registro.
- Optional HTTPS with your own certificate. / HTTPS opcional con tu propio certificado.
- Windows: installer, tray icon with notifications, start with Windows, firewall rule for private networks only. / Windows: instalador, ícono junto al reloj con avisos, arranque con Windows y regla de firewall solo para redes privadas.
- Optional iPhone shortcut (Share → Puente) with its own revocable key. / Atajo opcional del iPhone (Compartir → Puente) con su propia llave revocable.
- Spanish and English. / Español e inglés.
